# qin-codex-skills

Public mirror of Qin's user global Codex skills from `~/.codex/skills`.

This repository stores global skill source files only. Do not copy the repository `.git` directory into `~/.codex/skills`.

## Skills

### [`code-skill`](./code-skill/)

Unified code skill for coding approach, Spark routing, prompt generation, Python rules, Unity C# rules, and bounded code tasks.

### [`test-skill`](./test-skill/)

Real executable testing plus PDF evidence reports after code, UI, scripts, automations, generated assets, or content have been created or changed.

### [`verify-skill`](./verify-skill/)

General verification for workflows, local scripts, UI/UX, generated artifacts, skill edits, and process optimizations. UI verification routes through the local UI problem index plus `leonxlnx/taste-skill`.

### [`qin-skill-optimization`](./qin-skill-optimization/)

Optimize an existing skill or prompt-driven instruction layer from concrete failure evidence, pre-use review, or finalization checks.

### [`qin-codex-auth-swithc`](./qin-codex-auth-swithc/)

Inspect and switch saved Codex ChatGPT auth profiles under `~/.codex` without deleting existing auth files.

### [`qin-codex-skills-github-sync`](./qin-codex-skills-github-sync/)

Sync local global Codex skills with this GitHub mirror without placing `.git` metadata inside `~/.codex/skills`.
