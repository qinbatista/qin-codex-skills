## Project Cache artifact policy

Before project-support writes,resolve `<project-root>`;put tests, intermediate code, logs, debug, receipts, and probes in `<project-root>/Cache/` under `Cache/tests/<task>`, `Cache/debug/<task>`, or `Cache/images/<task>`.Never use `~/.codex/cache`,`~/.codex/tmp`,or project-root `tmp/`,`tests/`,`work/`;OS/tool temp is excluded.

All local-machine paths in skills/scripts/code/config/docs/commands must be project-root-relative or runtime-derived;never hard-code POSIX home or Windows drive paths;run from project root with native path APIs.

Unavoidable external absolute paths may be in project-root `Cache/cache_path.json`;it is untracked AI-only state, must be validated with bounded platform-aware discovery, preserve unrelated keys, and never store credentials or publish. Project code must never read it.
