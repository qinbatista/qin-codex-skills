# qin-codex-skills

- This repository owns the eight public global skills. Each skill owns its instructions, references, runtime helpers, and tests. Keep concepts concise; project-specific implementations belong in project skills.
- The user's selected model and effort read applicable skills and relevant project memory, define goals, and perform skill-governed work. Only genuinely skill-independent tasks use adaptive model selection. Mechanical tool calls need no extra model.
- Disclose score/band, selected model/effort and route early, then delegated goals, scores, pairs, dependencies and actual outcomes. Distinguish assignments from runtime proof. Plan only when useful. Parallel branches need disjoint ownership and explicit dependencies. The root integrates and completes the task.
- Verify consequential changes inside the active task using the smallest convincing check. Simple value-only edits skip verification unless requested. Do not start or compile a whole project unless requested.
- Ending is memory-only, using the user's selected model and effort after task verification. For the user-authorized Ending lifecycle, create one separate visible projectless memory task, link its acknowledgement and read back the saved result. It does not verify, repair or benchmark. Missing memory/no durable change is an explicit skip; unavailable task creation stays pending.
- Read only relevant project memory and explicitly shared preferences. Missing memory is a normal skip. Preserve project isolation, useful history, privacy, and unrelated edits.
- `task-analyze-skill` owns model policy and runners; `workflow-skill` owns coordination; `verify-skill` owns in-task evidence; `project-memory-skill` owns recall and durable summaries.
- `management-skill/scripts/sync_global_skills.py` owns installation and publication. Install with locking, recoverable backup, and rollback; preserve unrelated skills, user AGENTS, and private routing history. Update global AGENTS only when authorized. Publish only when requested, after the release gate.
- Follow [portable, quiet execution](code-skill/references/skill-platform-compatibility.md) for scripts, tests, and background work: prefer Python, preserve supported platform differences, and capture output without opening windows. Nested Codex uses `approval_policy="never"`; never click an approval prompt or restart another task.
- Keep support artifacts in `Cache/tmp-*`. Dated or remote Cache directories need explicit retention; formal tests remain source. Machine paths belong only in the untracked AI registry. Clean only exact task-owned disposable resources after readback.
- Definition of done: current instructions and executable behavior agree, relevant tests pass, and source/install/publication status is reported accurately.
