# 紫微斗数推演逻辑

## 基本原则

- 先锁命盘，再解释。只要出生输入、历法、性别、时区、闰月有变，必须重排，不沿用旧解读。
- 事实和推演分层。事实来自 profile 和排盘结果；推演来自命盘结构、三方四正、四化、大限、流年/流月触发。
- 解析必须独立成 `analysis` 文件；固定推算必须独立成 `calculation` 文件，二者不能混写。
- 所有判断要写成“依据 -> 倾向 -> 风险 -> 建议”，避免无依据断语。
- 不确定的流派差异要显式标注，不能混用不同流派规则。

## 证据优先级

1. 已交叉验证的出生资料和原局十二宫。
2. 命宫、身宫、命主、身主、五行局、来因宫。
3. 生年四化和四化落宫链路。
4. 命宫三方四正与相关领域宫位。
5. 当前大限、目标流年、未来五年、流月触发。
6. 杂曜、神煞、亮度等辅助证据。

## 文件读取顺序

1. 先读 profile，确认出生资料和 `verification.status`。
2. 再读 calculation，确认历法、时辰、命身宫、五行局、紫微/天府、四化。
3. 再读 chart，确认十二宫事实。
4. 最后读 analysis，检查解释是否都有 chart/calculation 证据。

## 固定五段报告逻辑

所有紫微斗数解读、续算更新和用户临时询问都默认使用同一套解读模板。正式报告完整展开；局部询问压缩展开，但仍保留“星盘摘要 -> 结论总览 -> 证据 -> 风险 -> 建议 -> 边界”的顺序。

### 0. 星盘摘要

先给大概星盘，不把完整十二宫表塞进正文：

- 出生资料、公历换算、时辰、时间基准。
- 命宫/身宫、命主/身主、五行局、来因宫。
- 生年四化。
- 本地完整星盘 Markdown 和固定推算文件路径。

### 1. 命运全景

输出此命盘的整体人生地图：

- 一句话总览：综合命宫、身宫、四化、当前大限。
- 人生主轴：性格、事业、财富、关系、迁移、身心状态。
- 大限总览：从当前年龄附近向前后展开，写阶段主题、机会、风险、建议。

### 2. 宿命解构

拆原局，不先谈年份：

- 命宫与身宫：一个写底层定位，一个写现实承载方式。
- 三方四正：围绕命宫、财帛、官禄、迁移等实际宫位解释结构。
- 四化链路：禄看资源与顺势，权看控制与责任，科看名声与缓冲，忌看执念、代价和需要修正之处。
- 六大领域：事业、财富、关系、家宅、身心、学习表达。

### 3. 流年影像

针对目标年份生成年度影像：

- 先确认目标年份和对应流年资料是否已计算。
- 年度关键词必须能回溯到流年宫位、流年四化、当前大限或原局触发。
- 输出机会窗口、风险窗口、行动策略。
- 如果没有可靠流年排盘数据，只能写“待计算”，不能凭原局硬推具体月份。

### 4. 未来五年推演

针对连续五年做趋势表：

- 每年单独计算或引用年度资料。
- 每年输出年度主线、事业、财富、关系、状态、关键建议。
- 不把五年写成同一个静态性格分析。
- 标出跨年连续主题，例如换大限、四化重复触发、事业/财帛轴持续受冲。

### 5. 流月时局行事历

针对目标年份十二个月生成行事历：

- 先确认使用的流月算法、月份范围和起止日期。
- 每月输出时局主题、适合行动、谨慎事项、关键词。
- 适合行动要可执行，例如签约、复盘、求职、学习、沟通、休整。
- 若流月资料未计算，生成空模板或标为待排，不编造具体月运。

## 语言风格

- 中文输出要清晰、克制、可执行。
- 用“倾向、容易、适合、需要留意”表达判断。
- 不写恐吓式结论，不把命理当确定事实。
- 重要判断必须引用对应宫位或星曜证据。
