# qin-codex-skills AI index

Start with `project_ai_index.py route --project-root ROOT` from the installed Management Skill to read only the compact module menu. Select `--module ID`, then `--target TARGET` to read the current method or bounded key-line fragment. [index.json](index.json) owns the maintained metadata; do not load the whole manifest for routine navigation. For every local code edit, including tests, use [code navigation](../../../management-skill/references/project-ai-index.md#code-navigation), exact-scope memory and only necessary related contracts. Reuse unchanged context and refresh touched targets after edits. The source directories contain the public global Skills; this index is project-only and must never be installed globally or bundled as a plugin Skill.

Choose shared rules by the action:

| Action | Read |
| --- | --- |
| Source changes, installation, Git delivery or publication | [Repository and assets](rules/repository.md) |
| Creating/moving code, instructions or routes | [Structure](rules/structure.md) |
| Tests, evidence or release acceptance | [Verification](rules/verification.md) |
| Task coordination, writes, tools or cleanup | [Execution and resources](rules/execution.md) |
| Recall, durable knowledge or Ending | [Memory and Ending](rules/memory.md) |

Use Management's [automatic project AI index](../../../management-skill/references/project-ai-index.md) at start/resume, on accepted intent/ownership changes and before delivery. Its helper owns inspection, selected routing and guarded updates. A missing route calls for a bounded name/symbol lookup in the likely owner and a verified route repair. Read a dependency only when its stated reason applies; do not recursively load every linked file or all eight Skills.

Keep detailed policies in their linked owning Skill. This map records stable responsibilities, not current test results, hashes, machine paths or execution state. Repeated unrelated context is evidence to explain a proposed module split; source restructuring still needs the user's direction. Preserve existing scoped guidance and user decisions.
