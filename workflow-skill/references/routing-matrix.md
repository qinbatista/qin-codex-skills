# Task ownership

| Work | Model | Evidence | Memory |
| --- | --- | --- | --- |
| Skill-governed code, UI, prompts, or design | User-selected model and effort | Relevant in-task check | Concise durable changes |
| Independent mechanical tool call | No additional model | Output readback | Only if useful |
| Independent work without governing skills | Adaptive complexity/history choice | Smallest convincing check | Same project only |
| Simple value edit | Selected model if skill-governed | Skip unless requested | Usually skip |
| Memory summary | User-selected model and effort | Read back the write | No verification or repair work |

Read available relevant memory before work. Absence is a normal skip. A subtask remains skill-governed when its goal inherits code or design constraints, even if it is implemented with a script.
