# 2D Bone Animation

Use this skill whenever the user asks to create, edit, review, or rerun Unity 2D bone animation for this project.

## Required Reading

- `references/project-rules.md`

## Core Workflow

1. Preflight the source sprite and Unity importer settings first.
2. Bind or verify bones in Unity Sprite Editor/Skinning Editor.
3. Use ChatGPT references only when they help; skip them when they make walk wrong or complicated. When image generation is needed, route it through the ThisIsMyOregon image-generation skills and style rules.
4. Author animation in Unity using `Animator`, `.anim` `Animation Clip`, bone Transform keys, and `Sprite Skin`.
5. Export and show a Unity-rendered GIF from the actual Sprite Skin result for every action in the current scope.

Never call a static pose, edited PNG, generated frame sheet, or external render the finished Unity bone animation.
