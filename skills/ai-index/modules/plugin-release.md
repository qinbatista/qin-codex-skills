# Codex plugin release

The [plugin manifest](../../../plugins/qin-codex-skills/plugin.json) and [Skill list](../../../plugins/qin-codex-skills/skills.json) select the user-global payload. Each top-level Skill folder remains the source. The [release action](../../../.github/actions/publish-plugin/publish.py) reads tracked files from the exact source commit and creates the `codex/plugin` Git marketplace tree with only its catalog, manifest and selected Skill files.

The [publish workflow](../../../.github/workflows/publish-plugin.yml) runs on `master` and advances the package ref with normal fast-forward history. `qin-unity-skills` uses the same composite action with its own manifest and Skill list. The clean-clone gate copies the release inputs into the source candidate for index validation. The [install instructions](../../../README.md#install-the-global-plugin) use Codex's user-global install and remove commands. Verify the shipped inventory and the native install, replacement and removal flow if the boundary changes.
