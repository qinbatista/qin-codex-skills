# Codex plugin release

The [plugin manifest](../../../plugins/qin-codex-skills/plugin.json) and [Skill list](../../../plugins/qin-codex-skills/skills.json) select the user-global payload. The [release action](../../../.github/actions/publish-plugin/publish.py) reads tracked files from the exact source commit and creates a Git marketplace tree containing its catalog, manifest and selected Skill files.

Stage Skill changes and run the shared release action's `--prepare` command to include the native marketplace in the source commit. The [publish workflow](../../../.github/workflows/publish-plugin.yml) points `refs/tags/codex/plugin` at `master`. For an unprepared direct push it adds the generated files in a single fast-forward on that same history. The publisher checks both remote refs and uploads the skills-only ZIP to the tagged release. The [grouped installer](../../../management-skill/scripts/install_skill_pack.py) reads the ZIP and supports the existing tag archive during rollout. Native Marketplace clients can use the same tag.
