# Codex plugin release

The [plugin manifest](../../../plugins/qin-codex-skills/plugin.json) and [Skill list](../../../plugins/qin-codex-skills/skills.json) select the user-global payload. The [release action](../../../.github/actions/publish-plugin/publish.py) reads tracked files from the exact source commit and creates a Git marketplace tree containing its catalog, manifest and selected Skill files.

The [publish workflow](../../../.github/workflows/publish-plugin.yml) publishes each changed package as a single snapshot at `refs/tags/codex/plugin`. The lease binds replacement to the observed tag, and publication verifies the current `master` and reads the new tag back. `qin-unity-skills` calls the same action with its own manifest and list. The [shared installer](../../../management-skill/scripts/install_skill_pack.py) downloads the `codex/plugin` archive and replaces direct Skill children under `~/.agents/skills/<pack>/`. Native Marketplace registrations use the same `codex/plugin` ref. See the [installation commands](../../../README.md#install-the-global-skill-pack).
