# Codex plugin release

The [plugin manifest](../../../plugins/qin-codex-skills/plugin.json) and [Skill list](../../../plugins/qin-codex-skills/skills.json) select the user-global payload. Each top-level Skill folder remains the source. The [release action](../../../.github/actions/publish-plugin/publish.py) reads tracked files from the exact source commit and creates the `codex/plugin` Git marketplace tree with only its catalog, manifest and selected Skill files.

The [publish workflow](../../../.github/workflows/publish-plugin.yml) advances the package ref from `master` with normal fast-forward history. `qin-unity-skills` uses the same action with its own manifest and list. The [shared installer](../../../management-skill/scripts/install_skill_pack.py) reads the Git release and writes direct Skill children under `~/.agents/skills/<pack>/`. It replaces or removes that one directory. The publisher uses the same file filter. The native Marketplace keeps its original cache layout for users who choose it. See the [installation commands](../../../README.md#install-the-global-skill-pack).
