# Task Analyze

Start at [SKILL.md](../../../task-analyze-skill/SKILL.md). Its [global entry rule](../../../task-analyze-skill/assets/global-agents-entry-rule.md) is the maintained installation input for global AGENTS behavior; it is not permission to overwrite user AGENTS.

Use [Complete action requests](../../../task-analyze-skill/SKILL.md#complete-action-requests) to define the final result, acceptance criteria and feasibility at startup, resolve routine choices without questions, and verify every achievable requirement before ending. Workflow applies the same endpoint to external jobs, verification and Git delivery. Task Analyze also owns concise one-time chat naming and final reporting of actual Skill and memory use.

During task design, check for repeatable steps with stable inputs and checkable results. Plan a suitable local command and its acceptance check with [Optimization](../../../optimization-skill/SKILL.md#run-repeatable-work-locally).

The startup block invokes the current project's Cache rules, Workflow cleanup checkpoint and Management inventory refresh before implementation or allocation. An opted-in daily sweep uses the checkpoint's `daily_sweep` status and an explicit verified project selection. Inline closeout also applies to ordinary questions and source investigations, subject to read-only and consent boundaries. Workflow and Project Memory own these operations.

For automatic index mechanics use Management. For the final memory list, follow [Project Memory's recall evidence rules](../../../project-memory-skill/references/project-knowledge.md#report-memory-used). Verification belongs in the active task, with the [project test registry](../../../.agents/skills/testing-skill/SKILL.md) identifying retained contract coverage.

The [global Skill routing guide](../../../task-analyze-skill/references/global-skill-routing.md) maps related work to installed entries. A user-level Codex `developer_instructions` setting can require this routing across projects without changing their local guidance. Read the effective configuration and exercise a fresh implicit task to verify activation.
